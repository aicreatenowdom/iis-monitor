## Understand the activity behind your websites

ServerSight Pro brings website requests, bandwidth, HTTP errors and Windows resource measurements into one desktop workspace. Choose the IIS sites you want to watch, record a session and keep reports you can review later.

For home labs, independent developers, small businesses and server administrators, it offers a practical way to see what is happening at your Windows IIS origin. Monitoring reads existing information without changing your websites, application pools, bindings, logging fields, DNS or firewall rules.

## One workspace, six useful views

| View | What you can see |
| --- | --- |
| **Live Overview** | Requests, connections, queues, network throughput, CPU, available memory, IIS worker resources and disk activity, with recent time-series charts. |
| **LAN & External** | Separate views of local-network and public TCP/UDP activity, alongside whole-adapter measurements. |
| **Sites & Content** | Selected websites, completed downloads, uploads and URLs, with request counts and transferred bytes. |
| **Requests & Errors** | Completed request history, 4xx/5xx filtering, readable HTTP status explanations and suggested actions. |
| **Full Logs** | Local CSV, TXT and JSON reports, with ZIP packaging for a finalized session. |
| **Safety & Help** | Measurement guidance, license activation and controls for product-owned results. |

Core telemetry updates every three seconds. Detailed live tables publish up to once a minute when changed, and at finalization.

## From a question to a saved report

1. **Choose your sites.** Select the IIS websites you want included.
2. **Set your recording window.** Choose 1, 6, 12, 24, 48, 72 or 168 hours and start monitoring.
3. **Explore the activity.** Move between server, network, content and request views.
4. **Keep the evidence.** Use **Stop & Finalize** to save the session, then create a ZIP when you want to share it.

Results are saved locally, normally in the application's results folder on your Desktop. They are not automatically uploaded. Reports can contain server and client details; review them before sharing. Recording remains subject to available storage, system availability and license duration.

### Understand what the numbers mean

Connection counts are not unique visitors. Requests served entirely by a CDN cache never reach IIS and are outside the origin view. Whole-adapter traffic includes other applications and protocols, so it will differ from selected-site request totals. Available details depend on existing log fields and Windows counters; individual request detail may be sampled at high load.
